# Ideal Outcomes — Session ID Lookup Feature

## Locked Ideal Outcomes

| Actor | [O] Outcome |
|---|---|
| **USER** | Retrieves any past session by pasting its full UUID without waiting |
| **USER** | Finds relevant sessions by typing any portion of a session ID |
| **AGENT** | Reads and extends CommandPalette code using the same component and memoization patterns as existing result types |
| **SYSTEM** | Resolves session lookups across all projects in parallel, returning the first match |
| **SYSTEM** | Matches sessions by partial ID prefix, returning all matches ranked by recency |
| **SYSTEM** | Exposes a fully initialized ConfigManager singleton to all callers after startup |
